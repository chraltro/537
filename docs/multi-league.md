# Multi-league expansion — contracts

Decided by the session lead; both implementation agents build to this. Neither
agent edits the other's files.

## Output contract (Agent A produces, Agent B consumes)
- site/data/leagues.json — manifest (regenerated by the pipeline; league entry
  gains "ready": true once its directory is written). Field meanings:
  ucl_places = Champions League line used by the sim; releg_places = DIRECT
  relegation spots only; releg_note = play-off wording or null. Agent A must
  verify ucl_places per league for 2026-27 (UEFA performance spots) with
  sources and correct the manifest from code.
- site/data/<slug>/{forecast,matches,schedule,history,predictions,season_report,recap,sim_input,backtest}.json
  — same schemas as today's PL files, with these additions:
  forecast.json += "league" {slug,name,country,ucl_places,releg_places,releg_note,n_teams};
  sim_input.json += "ucl_places","releg_places","n_teams".
- The legacy flat site/data/*.json for the PL remains until Agent B's site
  reads the new layout, then the lead removes it at integration.

## Model rules (Agent A)
- Per-league market anchor file data/market_priors/<slug>.json; only the PL
  file exists (moved from data/market_priors.json); absent file => weight 0.
- Promotion/carryover calibration per league from its own 2nd tier; if the
  2nd-tier history is too thin (<8 promoted-club pairs), fall back to the
  PL-fitted constants and say so in a comment.
- normalise() must fold accents (Málaga == Malaga); add aliases + colours for
  every 2026-27 club in all five leagues to data/team_meta.json.
- Old CSV seasons in some leagues lack shot columns; the coverage-weighted
  blend already tolerates that — add a test proving it.
- Full pipeline for all five leagues must stay under ~12 min (PL backtest may
  stay full; other leagues may restrict backtest seasons to keep the budget).

## Site rules (Agent B)
- League switcher in the masthead chrome; selection propagates as ?lg=<slug>
  through EVERY internal link and survives reloads; default premier-league.
- All pages read site/data/<lg>/...; leagues with "ready": false appear in the
  switcher disabled ("coming soon" tooltip) and never 404.
- League-dependent wording comes from the manifest (UCL line count, direct
  relegation spots, play-off note). No hardcoded "top 5" or "bottom 3".
- The sim worker takes ucl_places/releg_places/n_teams from sim_input.json
  instead of constants.
